# Модули РКО

Каталог будущих программных модулей цифровой платформы Русского космического общества.

Планируемые направления:
- библиотека и поиск;
- карта знаний и научных школ;
- персоналии;
- проекты и публикации;
- синхронизация с `cosmatica.org`;
- AI-поиск по разрешённому для индексации корпусу.
