## Что здесь опубликовано

- 31/31 строк исходной таблицы «Макеты страниц cosmatica.org».
- Для каждого пункта: исходный URL, новый тип шаблона и отдельный review-маршрут.
- Единая дизайн-система и адаптивные состояния.
- Особые требования Павла встроены в соответствующие шаблоны.
- Figma синхронизирована на уровне компонентов и семейств экранов.

### Открыть

- `index.html` — полная карта 31 страницы.
- `page.html?p=projects` — пример каталога проектов.
- `page.html?p=project` — карточка проекта.
- `page.html?p=departments` — отделения.
- `page.html?p=library` — библиотека.
- `page.html?p=donate` — поддержка РКО.
- `page.html?p=login` — вход.
- `page.html?p=search` — поиск.

Полный реестр находится в `SCREEN_MATRIX.md`.

## Архитектура

`routes.js` — 31 маршрут и связь с исходными страницами Cosmatica.

`page.html` + `site.js` — общий renderer (отрисовщик страниц), который собирает нужный экран из типа шаблона. Благодаря этому изменения дизайн-системы не расходятся между десятками копий.

`site.css` — единый визуальный слой и адаптивность.

## Принцип

Это не новый сайт с нуля и не замена содержания Cosmatica. Это эволюционная дизайн-интеграция:

**действующий смысл и маршруты → единые шаблоны → современный интерфейс → перенос в production-код Павла после review.**

## Проекты и НС-2117

Публичный слой проекта показывает:

`статус → смысл → связь с НС-2117 → след → следующий этап → участие`.

Внутренние аналитические поля и служебные оценки НС-2117 в публичный интерфейс не выносятся.
