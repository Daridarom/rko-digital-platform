# Интеграция дизайна Павла · 2026-10

Статус: **рабочая интеграционная ветка, не production**.

## Цель

Свести в одну реализуемую систему:

- утверждённую архитектуру действующей платформы РКО;
- новый визуальный язык РКО / Cosmatica / «Соэволюция»;
- существующие материалы и маршруты `design/cosmatica-2026` и `design/coevolution-2026`;
- модель проектов с НС-2117;
- последующий перенос в живой интерфейс без изменения production до отдельного согласования.

## Принцип интеграции

Мы не перерисовываем каждую страницу как независимый макет. Сначала фиксируем шаблоны и компоненты, затем раскладываем по ним полный набор утверждённых страниц. Это позволяет Павлу/SADI видеть не декоративный концепт, а систему, которую можно последовательно переносить в код.

## Что сохраняем

- действующую информационную архитектуру и полезные пользовательские маршруты;
- бренд РКО;
- существующие данные и материалы;
- разделение публичной информации и внутренних служебных оценок;
- обратимость изменений до согласования.

## Что добавляем

- единый визуальный язык;
- проектную модель: статус → смысл → связь с НС-2117 → след → следующий этап → участие;
- профиль участника как рабочую точку входа;
- «Соэволюцию» как отдельный новый смысловой слой, без смешивания со служебной частью.

## Правило публикации

Ветка `design/pavel-integration-2026-10` — лаборатория интеграции. В `main` ничего не переносится автоматически. Слияние возможно только после визуального read-back и отдельного подтверждения.
