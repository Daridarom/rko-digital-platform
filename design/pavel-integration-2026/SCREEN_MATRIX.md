## Правила единого стандарта

1. Содержание и функция исходной страницы сохраняются; меняется визуальная и компонентная подача.
2. Один тип контента — один переиспользуемый шаблон, без локальных копий.
3. Desktop и mobile считаются обязательными состояниями.
4. Проекты: публично — статус, смысл, связь с НС-2117, след, следующий этап, участие; внутренние аналитические оценки не публикуются.
5. Исходный URL хранится рядом с макетом для проверки Павлом.
6. Figma хранит эталонные компоненты и семейства; GitHub — основной review-контур и исполняемый preview.
7. Изменения в текущую Cosmatica не вносятся из этого каталога автоматически.
