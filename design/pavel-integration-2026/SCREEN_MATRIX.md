## Критерий готовности семейства

1. Сверена фактическая страница/маршрут.
2. Определён общий шаблон.
3. Компоненты переиспользуются, а не копируются.
4. Desktop и mobile проходят визуальный read-back.
5. Нет внутренней служебной информации в публичном UI.
6. Есть понятное соответствие существующему маршруту либо явно отмечен новый маршрут.
7. После согласования шаблон может быть перенесён в production отдельным изменением.
