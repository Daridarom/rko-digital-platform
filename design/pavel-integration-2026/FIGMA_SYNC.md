# Figma ↔ GitHub sync

Основной review: GitHub.
Figma используется как эталон компонентов, размеров, токенов и семейств экранов.

## Соответствие

| GitHub template | Figma |
|---|---|
| home | 01 · Главная / desktop |
| projects | 02 · Проекты / каталог |
| project | 03 · Проект / карточка |
| profile | 04 · Профиль участника |
| 31-route map | 05 · Карта 31 маршрута |
| list / article / events | 06 · Контент / список + статья |
| directory / detail / departments / contacts | 07 · Каталоги / отделения + партнёры |
| library / book | 08 · Библиотека / каталог + книга |
| auth | 09 · Авторизация / формы |
| donate | 10 · Поддержать РКО |
| search | 11 · Поиск / 2 состояния |

## Общие параметры

- Font: Roboto.
- Primary navy: #0D0C39.
- Primary red: #5D000F.
- Accent gold: #FFCA38.
- Surface: #FFFFFF / #F5F5F8.
- Border: #E5E5EC.
- Desktop reference width: 1280.
- Mobile breakpoint в GitHub preview: 640px / 900px по типу сетки.

Любое изменение визуального языка сначала должно быть отражено в общей системе, а не исправляться локально на одной странице.
