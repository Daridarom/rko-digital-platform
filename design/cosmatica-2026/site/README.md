# Cosmatica 2026 · полный интерфейсный контур

Опубликованный дизайн-контур Русского космического общества на основе утверждённого визуального направления.

## Состав

- 32 интерфейса и состояния.
- Единая шапка, навигация, фирменная палитра и адаптивная сетка.
- Отдельные типы для новостей, мероприятий, структуры РКО, партнёров, отделений, проектов, состава, профилей, материалов, библиотеки, форм и поиска.
- Поиск разделён на два самостоятельных состояния: пустой запрос и результаты.
- Проектная страница предусматривает разные состояния боковой колонки и поддержки.
- Отделения используют алфавитную навигацию и многоколоночную сетку.
- Страница поддержки переработана как самостоятельный пользовательский сценарий.
