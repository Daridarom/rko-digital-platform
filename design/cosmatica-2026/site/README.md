## Как устроена сборка

`routes.js` задаёт 32 интерфейса (31 тип страниц действующего сайта, включая два состояния поиска).

`content.js` содержит адаптированные сведения для каждого интерфейса и пять вариантов страницы проекта.

`site.js` содержит повторно используемые шаблоны, компоненты, навигацию, поиск, фильтры, календарь и логику состояний.

`site.css` задаёт единый визуальный язык, доступность и адаптивное поведение.

`assets/` хранит проверенные изображения и официальный знак РКО.

## Границы

Это полноэкранный дизайн-контур с содержанием из действующей Cosmatica для проверки и интеграции. Он не заменяет серверную CMS, не принимает пароли или пожертвования и пока не содержит полный архив всех оригинальных длинных публикаций. Финальная интеграция в production требует сверки исходных URL, данных, прав и подключения серверных функций.

Действующий сайт РКО при публикации этого каталога не изменяется.

## Самостоятельный режим просмотра

Слои `demo-data.js`, `demo.js` и `demo.css` адаптируют 32 интерфейса к цельной самостоятельной демоверсии:

- внешний сайт и его адреса не присутствуют среди пользовательских переходов;
- мобильное меню открывается поверх содержимого, а не сдвигает страницу;
- поиск сжимается в удобную строку на телефоне и показывает результаты текущего запроса;
- все разделы открываются внутри демо;
- формы, выбор поддержки и проектные сценарии демонстрируются локально, без отправки данных, платежей и создания учётных записей;
- 7 вариантов проекта представлены самостоятельными маршрутами.

Структурная проверка: `node qa/check.mjs`.

Браузерный тест: `node qa/demo-smoke.mjs` с установленным Playwright. Он проверяет 32 интерфейса на компьютере и телефоне, отсутствие внешних переходов, работу меню, поиска, форм и проектных сценариев. Автоматический запуск настроен через GitHub Actions.

Данные первоисточника, включая ссылки для дальнейшей миграции, могут оставаться внутри модели данных как служебные поля, но не показываются как внешние действия в пользовательском интерфейсе.

**Границы:** это фронтенд-демонстрация для передачи дизайна и шаблонов. Полные тексты длинных статей, данные всей базы участников, реальные операции авторизации, пожертвования и синхронизация с CMS требуют интеграции с сервером действующего сайта. В демо операции не имитируют реальный приём денег и не отправляют пароли.
