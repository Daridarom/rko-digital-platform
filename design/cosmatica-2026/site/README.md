# Cosmatica 2026 · полный интерфейсный контур

Рабочая реализация нового интерфейса Русского космического общества в утверждённом визуальном направлении.

## Публичная версия

https://daridarom.github.io/rko-digital-platform/design/cosmatica-2026/site/

Карта интерфейсов:
https://daridarom.github.io/rko-digital-platform/design/cosmatica-2026/site/sitemap.html

## Архитектура

- `routes.js` — 32 маршрута и типы интерфейсов.
- `content.js` — структурированные данные каждой страницы и реальные варианты проектов.
- `site.js` — переиспользуемые компоненты и шаблоны страниц.
- `site.css` — единая дизайн-система, desktop/mobile, светлая/тёмная тема.
- `assets/rko-mark.svg` — канонический знак РКО «Прорыв».

Такое разделение сделано специально для последующей интеграции Павлом: данные можно заменить на CMS/API без переписывания визуального слоя.

## 32 интерфейса

В контуре представлены главная, новости, новости-детали, мероприятия, календарь, «Об РКО», управление, советы, партнёры, контакты, отделения, проекты, профиль участника, материалы, библиотека, книга, страница с вкладками, поддержка, авторизация и два состояния поиска.

Полный перечень: `INTERFACE_MATRIX.md`.

## Проекты

Один production-шаблон страницы проекта поддерживает реальные варианты данных:

- `view.html?p=project&id=gagarincy` — проект с изображением, новостями, мероприятиями и поддержкой;
- `view.html?p=project&id=rusleo` — целевой сбор средств с текущей/целевой суммой;
- `view.html?p=project&id=sns` — обычный общественный проект без сбора;
- `view.html?p=project&id=chotv` — медиа-проект с внешними площадками;
- `view.html?p=project&id=slovo` — конкурс с положением, событиями и участием.

Шаблон проекта содержит статус, направление, смысл, цель, историю/контекст, аудитории, тематику, форматы участия, документы, внешние площадки, новости, мероприятия и условный блок поддержки.
