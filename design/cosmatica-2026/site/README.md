## Как устроена сборка

`routes.js` задаёт 32 интерфейса (31 тип страниц действующего сайта, включая два состояния поиска).

`content.js` содержит адаптированные сведения для каждого интерфейса и пять вариантов страницы проекта.

`site.js` содержит повторно используемые шаблоны, компоненты, навигацию, поиск, фильтры, календарь и логику состояний.

`site.css` задаёт единый визуальный язык, доступность и адаптивное поведение.

`assets/` хранит проверенные изображения и официальный знак РКО.

## Границы

Это полноэкранный дизайн-контур с содержанием из действующей Cosmatica для проверки и интеграции. Он не заменяет серверную CMS, не принимает пароли или пожертвования и пока не содержит полный архив всех оригинальных длинных публикаций. Финальная интеграция в production требует сверки исходных URL, данных, прав и подключения серверных функций.

Действующий сайт РКО при публикации этого каталога не изменяется.
