# РКО — пользовательский и визуальный аудит по записи экрана

**Основание:** предоставленная запись экрана от 08.10.2026 (57 секунд, мобильный браузер).
**Объект:** самостоятельная статическая демонстрация нового дизайна в GitHub, не production CMS.
**Связанная задача:** [GitHub issue #67](https://github.com/Daridarom/rko-digital-platform/issues/67).

## Что показала запись

| Время (приблизительно) | Что увидел посетитель | Причина и исправление |
|---|---|---|
| 0–25 сек. | После аккуратно оформленной главной — длинный раскрытый дамп старой главной: изображения, календарь, списки новостей и повторные тексты | `source-home-archive` добавлял 47 исходных блоков и 45 изображений поверх нового главного экрана. Визуальный дубль убран; **оригинальный снимок оставлен в `data/source/home.json`**. Вместо дампа есть переход к полному каталогу |
| 5–20 сек. | Вертикальная цепочка изображений без понятной связи с текстом | На страницах со списком материалов дополнительная галерея больше не создаётся. В самих подробных материалах дополнительные изображения сгруппированы, с порядковыми подписями и открытием оригинала |
| 23–31 сек. | Важный текст «Об РКО» трудно просматривать на мобильном экране | Сохранён полный текст; добавлены аккуратная типографика, междустрочный интервал и навигация по существующим заголовкам длинных статей там, где есть не менее пяти подзаголовков |
| 32–40 сек. | Карточки отделений и затем повторный длинный список названий территорий | Убрано повторное отображение CMS-блоков после каталога карточек, сохранён один понятный набор переходов |
| 41–57 сек. | Вход и регистрация выглядят как разные несвязанные страницы, формам недостаёт пояснения | Сделано общее переключение «Вход / Регистрация», единые отступы и сообщение, что подлинная авторизация осуществляется только через CMS РКО |

## Дополнительные проблемы, выявленные по коду и в браузере

- **Книги:** исходная универсальная карточка придавала вертикальной обложке неправильные пропорции; отдельная страница книги не показывала обложку рядом с библиографическими полями. Введены портретные превью и отдельный обзор книги.
- **Отсутствующие обложки:** из 493 книжных карточек у 50 на исходной публичной странице нет обложки. Показывать честную заглушку, не создавать искусственный рисунок.
- **Зависимость от старого сервера:** успешно получено 111 оптимизированных локальных WebP-превью; 332 пока остаются ссылками на оригинальные публичные изображения. Во время проверки сервер `cosmatica.org` перестал отвечать на загрузку изображений. Для этой ситуации сделаны резервные надписи, код ошибки не должен приводить к пустой карточке. **Сами книжные PDF никогда не переносятся.**
- **Поиск:** локальный фильтр 15 карточек был непонятен как инструмент поиска во всём разделе. Сейчас эти действия разделены, поиск по архиву учитывает выбранную категорию и весь индекс.
- **Заголовки карточек:** отменена чрезмерная обрезка, для мобильного экрана увеличен размер текста, проверено отсутствие горизонтального переполнения.
- **Авторизация и пожертвования:** формы GitHub — только демонстрация оформления. Рабочие действия и защита данных должны реализовываться Павлом на стороне CMS.

## Полнота контента

По итоговой сверке: **5 203** найденных публичных URL, из них **4 823** публичных редакционных записи, **373** адреса с историческим HTTP 404, **1** с HTTP 403, **1** с некорректным ответом вместо профиля, **5** служебных маршрутов. Все **11** ранее отсутствовавших публичных статей восстановлены непосредственно с исходных страниц. Доступных, но не извлечённых статей больше нет: **0**. Остаточные исключения перечислены в `data/archive/unavailable-urls.csv` и `integration/ORIGIN_ACCESS_REPORT.md`.

Сохранены **1 420 публичных видеовставок** (видеофайлы не копируются), редакционные тексты, библиографические карточки, документы и связи материалов. Отдельно проверено отображение восстановленных страниц на мобильном и десктопном экране: `qa/recovered-articles.mjs`.


## Приёмка и ограничения

Проверки:
- `python3 qa/archive-integrity.py` — маршрут/структура/книги/видео всех 4 823 записей.
- `node qa/ux-video-regressions.mjs` — запись экрана: главная, отделения, библиотека, личный кабинет на 320/390/768/1440px.
- `node qa/listing-ux-and-category-search.mjs` — дубли, типографика, поиск по разделам.
- `node qa/demo-smoke.mjs`, `node qa/editorial-smoke.mjs`, `node qa/archive-browser-sample.mjs`, `node qa/mobile-refinement.mjs` — регрессии и реальное открытие материалов.
- `node qa/original-book-links.mjs` и `node qa/public-video-embeds.mjs` — неизменные ссылки и безопасная загрузка.

**Готовность к переносу в production:** только после подтверждения GitHub CI, визуальной приёмки заказчиком, уточнения формата интеграции и теста в staging CMS Павлом. Чат «СЕТЕНИЕ РКО» не использовался для отправки уведомлений, работающий сайт не изменялся.
