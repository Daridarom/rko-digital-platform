## Полный открытый архив сверх 31 шаблона
XML-карты и постраничные архивы выявили **5124 уникальных адреса**. Это не 5124 разных дизайна: сюда входят новости, статьи, книги (только публичные карточки), проекты, мероприятия, профили, глоссарий, газета, категории, отделения и другие материалы.
- Повторно получены все три ранее недоступные страницы новостей (`/news?page=70,71,72`): +45 адресов. Сетевая сверка архивных списков завершена.
- **373 адреса из старых карт при запросе отвечают HTTP 404, ещё один адрес возвращает HTTP 403**: это не опубликованные в данный момент страницы. Они сохраняются в служебном реестре с отметкой `not_found_404` и не отображаются как доступные материалы. Для передачи Павлу необходим отдельный список таких URL.
- Обнаруженный архив относится только к **публичному доступу**. Исключить авторизацию, приватные страницы, технические дампы, комментарии администрации и закрытые данные.
- Соответствие текста для каждой записи должно быть подтверждено сравнением извлечённого текста с видимым исходным содержимым. Код ответа 200 и заголовок не означают готовность.
- На сайте должна быть доступна навигация по всем разделам и полным спискам без перехода на старый сайт; внешние ссылки разрешены только там, где они предусмотрены оригинальным материалом.
- Для книг переносить **только карточку: название, автор, описание, обложка, категории, сопутствующие сведения**. Книжные PDF/DOC/DOCX не загружать на GitHub. Кнопка «Скачать» использует точный исходный `https://cosmatica.org/files/download/...` с действующего сайта РКО. Оригинальные адреса файлов не менять.

## Приёмка перед передачей Павлу
1. Все публичные страницы инвентаризации с сопоставленными маршрутами и типами шаблонов.
2. Полный читабельный текст; изображения не обрезаны; ссылки и документы ведут туда, куда должны.
3. Проверка на телефоне, планшете и десктопе; открытие меню, поиск, пагинация, фильтры, архивы.
4. Обработанные ошибки не скрываются: в отчёте отдельно список недоступных URL и неполных материалов.
5. В комплект передачи входят готовый исходный код, стили, сценарии, данные страниц, индекс маршрутов, руководство интеграции и протокол QA. Архив ZIP создавать только после полной проверки.
