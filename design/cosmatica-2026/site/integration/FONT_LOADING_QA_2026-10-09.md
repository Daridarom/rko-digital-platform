# РКО · проверка реальной загрузки шрифтов — 09.10.2026

## Обнаружено

Предыдущий Orbit Light задавал стек `Inter, Avenir Next, ...` без локального веб-файла `@font-face`. На проверочном Linux/Chrome фактически отображался **Liberation Sans**, несмотря на объявленный Inter в CSS. Экспериментальный режим `?design=poster` добавлял внешний `fonts.googleapis.com`, но при задержке или отсутствии Google Fonts заголовок также рисовался резервным шрифтом. Проверка только CSS `font-family` этого не выявляла.

## Исправлено

Шрифты хранятся на GitHub Pages вместе с сайтом, без запроса к стороннему CDN:

- `assets/fonts/inter-cyrillic-variable.woff2` (19 КБ) — кириллица; переменный вес 100–900.
- `assets/fonts/inter-latin-variable.woff2` (48 КБ) — латиница/знаки; переменный вес 100–900.
- `assets/fonts/russo-one-regular.ttf` (39 КБ) — кириллические плакатные заголовки, только `?design=poster`.
- Исходные тексты лицензий `assets/fonts/OFL-Inter.txt` и `assets/fonts/OFL-Russo-One.txt` включены в проект.

Основной сайт использует локальный `RKO Inter` (обычный текст и крупные заголовки), альтернативный эксперимент — Russo One только для H1 и основных H2. Предзагрузка кириллической части ускоряет первое отображение русскоязычного экрана. `font-display:swap` обеспечивает читаемость до завершения загрузки.

Файлы шрифтов получены из опубликованных библиотек Google Fonts / Fontsource по лицензии SIL Open Font License. Название **Russo One** обозначает современный индустриальный дизайн, а не аутентичное советское начертание.

## Read-back

`qa/selfhost-fonts-20261009.mjs` проверяет наличие файлов и лицензий, блокирует `fonts.googleapis.com`/`fonts.gstatic.com`, затем через Chrome DevTools Protocol смотрит реальные шрифты каждого использованного глифа, а не только CSS. Прогон охватывает 4 ширины × 3 режима = 12 браузерных сценариев и 5 локальных ресурсов.

Результат Chrome: обычная главная действительно нарисована **Inter**, плакатный режим — **Russo One**, текст анонса остаётся Inter. У всех заголовков `isCustomFont: true`. Отсутствуют обращения к Google Fonts и горизонтальное переполнение.

## Вопросы для следующего согласования с Павлом

Для второго поколения фирменной типографики можно сравнить Russo One с **Cuprum** (современный кириллический индустриальный гротеск), а для документально-исторических материалов рассмотреть **PT Serif**. Обе семьи требуют отдельного макета и согласования. Не следует заменять набор для длинных статей декоративным шрифтом.
