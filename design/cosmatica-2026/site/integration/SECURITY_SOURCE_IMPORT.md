# Безопасность импорта исходного сайта

**Критично:** при проверке публичной страницы исходного сайта 08.10.2026 обнаружен вывод внутренних объектов конфигурации CMS, включая параметры соединения с базой данных. Значения не сохранять в репозитории, отчётах, логах или демоверсии.

## Обязательные действия администратора исходного сайта

1. Немедленно отключить публичный вывод отладочных объектов и стеков конфигурации.
2. Сменить скомпрометированные реквизиты доступа к базе и другим сервисам, проверить права учётной записи и подключения.
3. Проверить журналы запросов и базы данных на несанкционированные обращения; оценить необходимость реагирования на инцидент.
4. Убедиться, что публичные страницы отдают только HTML с разрешённым содержимым, без дампов объектов CMS.
5. После исправления повторно проверить источник перед импортом материалов.

## Правило импорта

Не копировать сырой HTML целиком в GitHub или в клиентские JavaScript-файлы. До парсинга и публикации блокировать исходный документ при обнаружении признаков раскрытия конфигурации (например, `cmsDatabase Object`, `db_pass`, `db_host`, `document_root`, `session_save_path`, `cmsCore Object`). Сначала изолировать технический вывод, затем извлекать исключительно редакционные блоки из разрешённых контейнеров. Полный перенос содержания выполнять после устранения утечки и редакторской сверки.

Это отдельная проблема исходного сайта; публикация демонстрационной версии не должна её воспроизводить.
