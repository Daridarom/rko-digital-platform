# РКО — новая мобильная проверка по видеозаписи 9 октября 2026

Объект: опубликованный прототип Русского космического общества на GitHub Pages. Исходный сайт cosmatica.org не изменяется. Содержимое инвентаризированного публичного архива сохраняется.

## Что обнаружено в записи

- В мобильном разделе «Материалы» (конец записи) навигационные страницы «Конференции», «Публикации», «Медиа» и другие ошибочно обозначены как «Статья», хотя их архивный тип `articles-list` — раздел/подборка. Поскольку 18 ссылок ведут в подкатегории, прежний общий заголовок «Тексты и исследования» описывал их неточно.
- В карточке проекта «Академия научной фантастики» отдельно отражён статус «Действующий», а шаблон проекта далее показывал дополнительную строку «Статус: Проект РКО», противоречащую исходнику.
- В начале и середине записи включён режим «Для чтения» браузера. Он переформатирует страницу вне CSS сайта; это не доказательство поломки мобильной вёрстки.

## Исправления

1. Тип карточки на стартовой странице «Материалы» определяется по реестру исходных URL и типу архивной записи. Все 18 разделов честно обозначены как «Раздел», а не «Статья». Ссылка и оригинальное название каждого сохранены; переход проверен на примере «Конференции».
2. Мобильная сетка 390px показывает короткие названия в две колонки, длинные заголовки — на всю ширину. На экране до 350px используется одна колонка, на компьютере три; нет горизонтальной прокрутки.
3. Для проектов статус и направление выбираются из фактических именованных полей оригинальной архивной записи. Эти же метаданные не повторяются в отдельной карточке сведений. Шаблон больше не называет «Проект РКО» статусом по умолчанию.
4. Основные тексты, изображения, документы и все маршруты архива оставлены без редакционных изменений.

## Дополнительная проверка ссылок

Полный мобильный регрессионный тест выявил старые перенаправления через `cosmatica.org/redirect?url=` и внешние адреса в полях проектов без явной маркировки безопасности. Это не связано с версткой, но может нарушать требования к корректности переходов.
Теперь разрешённый адрес извлекается из исходной ссылки, если он имеет безопасный публичный HTTPS-адрес без учётных данных и локального IP. Внешние ссылки открываются в новой вкладке с `noopener noreferrer`, отказом от передачи источника перехода и явной пометкой внешнего контента. Записи авторских источников не изменены.
`qa/public-links-20261009.mjs` проверяет реальные публичные ссылки проектов SNS, «Чо-ТВ» и «Дружина Гагаринцев».
