# Правила фирменного стиля РКО для цифровых прототипов

Канонический источник: публичная папка РКО «Фирменный стиль»  
https://disk.yandex.ru/d/te4nlbRyWjh7nQ

Основной документ: **«РКО Правила фирменного стиля (03032018).pdf»**.

## Фирменные цвета

Для web используются RGB-значения из брендбука:

| Цвет | RGB | HEX | CMYK | Pantone |
|---|---|---|---|---|
| Золотой | 255 / 202 / 56 | `#FFCA38` | 0 / 21 / 88 / 0 | 123 |
| Красно-червлёный | 93 / 0 / 15 | `#5D000F` | 36 / 98 / 84 / 57 | 188 |
| Иссиня-чёрный | 13 / 12 / 57 | `#0D0C39` | 98 / 92 / 39 / 59 | 276 |

Оптимальная фирменная гамма — три цвета. Произвольные замены фирменных цветов не допускаются.

## Типографика

Фирменный шрифт — **Roboto**. Прямые и курсивные начертания используются для структурирования текстовой информации.

Для web-интерфейса:
- основной текст: Roboto Regular;
- второстепенный текст: Roboto Light / Regular;
- интерфейсные акценты и кнопки: Roboto Medium;
- курсив — только функционально, не как декоративный приём.

## Герб, знак и логотип

Официальный герб «Прорыв» и фирменный знак используются только в исходной форме.

Нельзя:
- обрезать знак;
- использовать `object-fit: cover`;
- помещать его в круглую или скруглённую маску;
- применять `clip-path`, `mask`, перспективные деформации, наклоны или повороты;
- перекрашивать или инвертировать фирменные цвета;
- менять композицию, пропорции или взаимное расположение элементов;
- дорисовывать поверх знака декоративные элементы;
- заменять знак самодельной упрощённой иконкой без отдельного утверждения;
- размещать полноцветный логотип на сложном фоне так, чтобы снижалась его идентификация.

Можно:
- масштабировать пропорционально;
- использовать `object-fit: contain`;
- добавлять свободное поле вокруг изображения;
- на тёмном или неоднородном фоне размещать полноцветный вариант на белой подложке с охранным полем;
- использовать линейную/однокрасочную версию только в предусмотренных брендбуком случаях.

## Охранное поле

Ширина охранного поля логотипа — **2× высота буквы L в фирменном знаке (2α)**.

В цифровом интерфейсе это правило является минимальным: рядом со знаком не должны располагаться текст, линии, рамки или декоративные объекты, нарушающие охранную зону.

## Минимальный размер

В брендбуке для печати:
- русская версия логотипа — не менее **54×16 мм**;
- английская — не менее **38×16 мм**;
- ориентир читаемости букв фирменного знака — около 4 pt.

Для web минимальный размер в пикселях отдельно не задан. Поэтому цифровой прототип должен проверяться по фактической читаемости и не переносить миллиметры механически в CSS.

## Фирменная геометрия

В знаке используется золотой вектор; в брендбуке указан угол **55.7558°**. В интерфейсе этот мотив допустим как вторичная графика только вне текста и только так, чтобы не имитировать/не изменять сам знак.

Эти правила действуют для главной страницы, внутренних страниц, мобильных и десктопных макетов, UI-kit и всех сравнительных прототипов.
