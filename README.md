# RKO Digital Platform

Цифровая платформа Русского космического общества.

Первый модуль — интерактивная электронная библиотека РКО: поиск, фильтры, карточки книг, обложки и прямые переходы на страницы материалов на cosmatica.org.

Рабочая структура:
- `apps/library/` — веб-интерфейс библиотеки;
- `modules/` — будущие программные модули РКО;
- `ARCHITECTURE.md` — архитектурные принципы платформы.
