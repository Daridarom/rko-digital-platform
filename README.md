# RKO Digital Platform

Цифровая платформа Русского космического общества.

Первый рабочий модуль — интерактивная электронная библиотека РКО: поиск, фильтры, карточки книг, обложки и прямые переходы на страницы материалов на `cosmatica.org`.

Параллельно ведутся два связанных направления:

- `design/cosmatica-2026/` — аудит и прототипы обновления Cosmatica, включая новую модель раздела «Проекты» через НС-2117;
- `design/coevolution-2026/` — исследовательский прототип «Соэволюции» и рабочая спецификация универсального паспорта проекта для целевого сетения.

Ключевые документы:

- `ARCHITECTURE.md` — архитектурные принципы платформы;
- `design/cosmatica-2026/NS2117_PROJECT_MODEL.md` — структура проектов на обновлённом сайте;
- `design/coevolution-2026/PROJECT_PASSPORT.md` — универсальный паспорт проекта;
- `design/coevolution-2026/STATUS.md` — текущий статус и границы работ.

Рабочая структура:

- `apps/library/` — веб-интерфейс библиотеки;
- `apps/reader/` — экспериментальный слой чтения;
- `modules/` — будущие программные модули РКО;
- `design/` — дизайн-лаборатория и спецификации, не production-код официального сайта.
